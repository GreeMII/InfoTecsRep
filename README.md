# Таблица отображения информации о пользователях

> **Разработано для InfoTecs**  
> Тестовое задание: React-приложение для управления пользователями с фильтрацией и сортировкой

---

## О проекте

Веб-приложение для отображения списком пользователей с использованием **React** и **DummyJSON API**. Реализован интерфейс с возможностью фильтрации, сортировки и просмотра детальной информации.

### 🚀 Демо
[https://GreeMII.github.io/InfoTecsRep]()

---

## Функциональность

### Основной функционал
- **Отображение таблицы пользователей** — все данные в табличном виде
- **Фильтрация** — по городу и возрастному диапазону
- **Сортировка** — по ФИО, возрасту, полу и номеру телефона
- **Пагинация** — постраничное отображение с настройкой количества записей
- **Детальная информация** — модальное окно с полными данными пользователя


Для работы с HTTP-запросами использовался FetchAPI. \
Для навигации использовался React Router

## Установка и запуск


### Шаг 1: Клонирование
```bash
git clone https://github.com/GreeMII/InfoTecsRep.git
cd в папку куда клонировали
```

### Шаг 2: Установка зависимостей
```bash
npm install
```


### Шаг 3: Запуск
```bash
npm start
```
Приложение будет доступно по адресу http://localhost:3000
